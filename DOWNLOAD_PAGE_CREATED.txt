⚙️  CONFIGURATION (REQUIRED):

Open: download.html
Find line: const DOWNLOAD_URL = 'https://your-download-server.com/...'
Replace with your actual download file URL

Examples:
• Telegram Bot: 'https://api.telegram.org/file/bot<TOKEN>/<path>'
• Dropbox: 'https://www.dropbox.com/s/abc123/file.exe?dl=1'
• Google Drive: (use direct download link)
• Your Server: 'https://yourserver.com/files/installer.exe'
• GitHub Release: 'https://github.com/user/repo/releases/download/v1/file.exe'
