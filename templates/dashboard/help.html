Quick Start Guide

1. Generate Payload

Create a payload to deploy on target systems. The payload will connect back to this C2 server.

2. Deploy to Target

Execute the payload on the target system. Once connected, the target will appear in the Targets page.

3. Execute Commands

Use the Command Center to interact with connected targets. Select a target and execute commands.

Available Commands

System Commands

  • whoami - Current user
  • hostname - System hostname
  • sysinfo - System information
  • pwd - Current directory

File Operations

  • ls - List files
  • cat [file] - Read file
  • download [file] - Download file
  • upload [file] - Upload file

Network

  • ping [host] - Ping host
  • netstat - Network connections
  • ifconfig - Network interfaces

Security

  • screenshot - Take screenshot
  • keylog start - Start keylogger
  • hashdump - Dump hashes
  • credentials - Harvest credentials

Features

Target Management

Track and manage all connected targets. View system information, connection status, and history.

Command Execution

Execute commands on targets with real-time output. Command history and autocomplete included.

File Management

Upload files to targets and download files from targets. Drag-and-drop support included.

Credential Harvesting

Automatically harvest credentials from browsers and applications. Export to CSV.

Keyboard Shortcuts

↑ / ↓ Navigate command history
