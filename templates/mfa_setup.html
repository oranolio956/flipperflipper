📱 Setup Instructions

  1. Open Microsoft Authenticator or Google Authenticator
  2. Tap the + button to add a new account
  3. Select "Scan QR code"
  4. Point your camera at the QR code above
  5. Enter the 6-digit code below to verify setup

🔒 Security Information

• Your authenticator app will generate a new 6-digit code every 30 seconds

• Keep your device secure - anyone with access can generate codes

• You'll receive backup codes after completing this setup

• Save backup codes in a secure location for account recovery
