📖 Usage Instructions

Bind Mode (Recommended)

• Target connects back to your server

• Leave "Your IP" empty to accept connections from any IP

• Make sure port 4433 is open on your firewall

Listen Mode

• You connect to the target

• Useful when target is behind NAT/firewall

• Target must be listening on specified port

Deployment

• Send the generated Python file to target

• Target runs: python stitch_payload.py

• Connection will appear in the Connections tab
