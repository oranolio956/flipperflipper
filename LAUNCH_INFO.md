## 📝 Known Limitations

### Non-Blocking Issues
1. **CryptoManager Key Persistence**
   - Keys work in-memory but file persistence has JSON serialization issues
   - Impact: Keys regenerated on restart
   - Status: Non-blocking for current functionality

2. **Redis Warnings**
   - "Redis unavailable, using memory fallback" warnings
   - Impact: Uses in-memory storage (fine for development)
   - Status: Expected behavior without Redis server

3. **Print Statements**
   - 57 print statements in route registration
   - Impact: Cosmetic, clutters logs
   - Status: Scheduled for cleanup

### Optional Features
- **python-magic:** File type detection limited without it
- **Redis:** Session persistence limited without it
- **Production HTTPS:** Requires reverse proxy configuration

## 🛠️ Troubleshooting

### Application Won't Start
```bash
# Check if port is in use
lsof -i :5000

# Check Python version
python3 --version  # Should be 3.8+

# Check dependencies
pip3 list | grep -i flask
```

### Can't Access URL
- Ensure Gitpod workspace is running
- Check if port 5000 is exposed
- Try refreshing the browser
- Check browser console for errors

### Authentication Issues
```bash
# Check database exists
ls -lh Application/stitch.db

# Check secret key
cat Application/.secret_key

# Check session configuration
python3 -c "from config import Config; print(Config.SESSION_COOKIE_HTTPONLY)"
```

### Redis Warnings
- **Expected in development** - uses in-memory fallback
- To install Redis: `sudo apt-get install redis-server`
- To start Redis: `redis-server --daemonize yes`
