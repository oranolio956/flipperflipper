### 6. Configure Nginx Reverse Proxy

```bash
# Exit from stitchrat user back to root
exit

# Create Nginx configuration
cat > /etc/nginx/sites-available/stitchrat << 'EOF'
server {
    listen 80;
    server_name 50.21.187.77;
    
    # Redirect HTTP to HTTPS
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name 50.21.187.77;
    
    # SSL Configuration (will be auto-generated by the app)
    ssl_certificate /opt/stitchrat/certs/cert.pem;
    ssl_private_key /opt/stitchrat/certs/key.pem;
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers ECDHE-RSA-AES256-GCM-SHA512:DHE-RSA-AES256-GCM-SHA512:ECDHE-RSA-AES256-GCM-SHA384:DHE-RSA-AES256-GCM-SHA384;
    ssl_prefer_server_ciphers off;
    
    # Security Headers
    add_header X-Frame-Options DENY;
    add_header X-Content-Type-Options nosniff;
    add_header X-XSS-Protection "1; mode=block";
    add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;
    
    # Proxy to Flask application
    location / {
        proxy_pass http://127.0.0.1:5000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        
        # WebSocket support
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        
        # Timeouts
        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 60s;
    }
    
    # RAT Server Port (for payload connections)
    location /rat-server {
        proxy_pass http://127.0.0.1:4040;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
    
    # Static files
    location /static {
        alias /opt/stitchrat/static;
        expires 1y;
        add_header Cache-Control "public, immutable";
    }
}
EOF

# Enable the site
ln -s /etc/nginx/sites-available/stitchrat /etc/nginx/sites-enabled/
rm -f /etc/nginx/sites-enabled/default

# Test and reload Nginx
nginx -t && systemctl reload nginx
```

### 7. Create Systemd Service

```bash
# Create systemd service file
cat > /etc/systemd/system/stitchrat.service << 'EOF'
[Unit]
Description=Stitch RAT Web Interface
After=network.target

[Service]
Type=simple
User=stitchrat
Group=stitchrat
WorkingDirectory=/opt/stitchrat
Environment=PATH=/opt/stitchrat/venv/bin
ExecStart=/opt/stitchrat/venv/bin/python web_app_real.py
Restart=always
RestartSec=10
StandardOutput=syslog
StandardError=syslog
SyslogIdentifier=stitchrat

# Security settings
NoNewPrivileges=true
PrivateTmp=true
ProtectSystem=strict
ProtectHome=true
ReadWritePaths=/opt/stitchrat

[Install]
WantedBy=multi-user.target
EOF

# Reload systemd and enable service
systemctl daemon-reload
systemctl enable stitchrat
```

## Security Considerations

⚠️ **IMPORTANT SECURITY NOTES**:

1. **Legal Compliance**: This is a penetration testing tool. Only use on systems you own or have explicit permission to test.

2. **Change Default Credentials**: Update the admin password in `/opt/stitchrat/.env`

3. **Firewall Rules**: The current setup allows connections from anywhere. Consider restricting access:
   ```bash
   # Allow only from specific IP
   ufw delete allow 443/tcp
   ufw allow from YOUR_IP to any port 443
   ```

4. **SSL Certificate**: The app will auto-generate a self-signed certificate. For production, use a proper SSL certificate.

5. **Regular Updates**: Keep the system and dependencies updated.

## Troubleshooting

### Common Issues:

1. **Port 5000 in use**: 
   ```bash
   sudo lsof -i :5000
   sudo kill -9 <PID>
   ```

2. **SSL Certificate Issues**:
   ```bash
   rm -rf /opt/stitchrat/certs
   systemctl restart stitchrat
   ```

3. **Permission Issues**:
   ```bash
   chown -R stitchrat:stitchrat /opt/stitchrat
   chmod -R 755 /opt/stitchrat
   chmod 600 /opt/stitchrat/.env
   ```

4. **Nginx Issues**:
   ```bash
   nginx -t
   systemctl status nginx
   tail -f /var/log/nginx/error.log
   ```
