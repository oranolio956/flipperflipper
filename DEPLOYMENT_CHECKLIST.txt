TROUBLESHOOTING

Problem: Can't connect to server
Solution: 
  1. Check firewall: ufw status
  2. Check service: systemctl status elite-rat
  3. Check port: netstat -tulpn | grep 5000

Problem: Login doesn't work
Solution:
  1. Check password: cat /opt/elite-rat/.env | grep PASSWORD
  2. Check logs: journalctl -u elite-rat -n 50
  3. Restart: systemctl restart elite-rat

Problem: Service won't start
Solution:
  1. Check logs: journalctl -u elite-rat -n 50
  2. Run manually: cd /opt/elite-rat && source venv/bin/activate && python3 web_app_real.py
  3. Look for Python errors

Problem: Changes not showing
Solution:
  1. Restart service: systemctl restart elite-rat
  2. Clear browser cache: Ctrl+Shift+R
